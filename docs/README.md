# Introduction

Welcome to the nbsp documentation.

This [mdBook](https://rust-lang.github.io/mdBook/) covers the nbsp software project, also known as non-breaking space. A thoughtful community forum platform.

## What is nbsp?

nbsp is intended to become a platform that small communities can reach for when they want to create their own space. Away from the hostile internet and all the problems that the big social media platforms come with. Anyone should be able to have their own space for their community.

It is heavily inspired by [Tildes](https://tildes.net) and [its plans to become a better place on the internet](https://blog.tildes.net/announcing-tildes). Due to many reasons however, the development of the Tildes software project has stagnated. And its creator [has recently announced that changes are extremely unlikely](https://tildes.net/~tildes.official/1vjt/any_significant_changes_to_tildes_are_extremely_unlikely).

For this reason, I've decided to have an attempt of my own at creating a better place online.
